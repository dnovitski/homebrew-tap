# dnovitski/tap

Homebrew formulae by [dnovitski](https://github.com/dnovitski).

| Formula | Description |
|---|---|
| [miniamp](https://github.com/dnovitski/miniamp) | Local PHP, MariaDB and phpMyAdmin for macOS without admin rights |
| [surfshield](https://github.com/dnovitski/surfshield) | Safe, policy-controlled web access for AI agents (MCP server and CLI) |

```bash
brew install dnovitski/tap/miniamp
brew install dnovitski/tap/surfshield
```
